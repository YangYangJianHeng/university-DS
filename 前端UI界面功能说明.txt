================================================================================
    组队星 (TeamStar) - 前端UI界面功能说明
    大学生竞赛/科研项目组队匹配与过程管理平台
    生成日期: 2026-06-29
================================================================================

  一、技术栈
  ------------------------------------------------------------------
  框架: Vue 3.4 + TypeScript 5.3
  UI库: Element Plus 2.5
  构建: Vite 5
  图表: ECharts 5.5 + vue-echarts 6.7
  动画: Three.js + GSAP
  路由: Vue Router 4
  状态: Pinia
  HTTP: Axios (封装 request.ts)
  Markdown: marked + DOMPurify
  ------------------------------------------------------------------

  二、页面总览（20个页面）
  ------------------------------------------------------------------
  A. 公共页面（无需登录）
    1. LandingPage    - 平台首页/落地页
    2. Login          - 登录页
    3. Register       - 注册页

  B. 鉴权页面（需登录，Layout布局内）
    4. Dashboard        - 个人工作台
    5. RecruitList      - 招募广场
    6. CreateRecruit    - 发布招募
    7. RecruitDetail    - 招募详情
    8. TeamList         - 我的团队
    9. TeamDetail       - 团队详情
    10. ProjectList      - 项目管理
    11. ProjectDetail    - 项目详情
    12. TaskList         - 任务中心
    13. CompetitionList  - 竞赛中心
    14. CompetitionDetail- 竞赛详情
    15. TeacherList      - 导师库
    16. AchievementHall  - 成果展厅
    17. Profile          - 个人中心
    18. AiChat           - AI助手

  C. 管理后台
    19. AdminDashboard   - 管理后台

  D. 布局组件
    20. Layout           - 侧边栏+顶栏主布局
  ------------------------------------------------------------------

  三、页面功能详解
  ------------------------------------------------------------------

  1. LandingPage（平台首页/落地页）
  --------------------------------------------------
  - 3D粒子背景动画（Three.js）
  - 顶部导航栏：Logo + "赛事/发现/社区"链接 + "开始使用"按钮
  - Hero区：标语"找到你的梦之队" + 平台介绍 + CTA按钮
  - 特色功能介绍卡片区
  - 数据统计展示区
  - 页脚区

  2. Login（登录页）
  --------------------------------------------------
  - 左右分栏布局，左侧品牌介绍，右侧登录表单
  - 手机号 + 密码登录
  - 表单验证（手机号格式、密码长度）
  - 登录成功后存储Token和用户信息到localStorage
  - 跳转至工作台
  - 底部"去注册"链接

  3. Register（注册页）
  --------------------------------------------------
  - 左右分栏布局，左侧品牌介绍，右侧注册表单
  - 字段：手机号、用户名、密码、确认密码、学号、姓名
  -  专业、年级、个人简介
  - 表单验证（手机号格式、密码一致性、必填项）
  - 注册成功后跳转至登录页

  4. Dashboard（个人工作台）
  --------------------------------------------------
  - 欢迎横幅（显示用户名 + "发布招募"快捷按钮）
  - 4个统计卡片：团队数量、项目数量、任务数量、消息数量
  - 趋势百分比（较上周变化）
  - 最近招募列表（快捷查看最新招募信息）
  - ECharts饼图：项目状态分布统计
  - 今日待办任务列表

  5. RecruitList（招募广场）
  --------------------------------------------------
  - 顶部操作栏：标题 + "发布招募"按钮
  - 筛选条件：
    - 项目类型（竞赛/科研/创新创业）
    - 状态（招募中/已关闭/已满员）
    - 关键词搜索
  - 招募卡片网格布局，每张卡片显示：
    - 项目图标、标题、类型标签
    - 发布人信息
    - 所需人数 / 已申请人数进度条
    - 截止日期
    - 技能标签
  - 分页器

  6. CreateRecruit（发布招募）
  --------------------------------------------------
  - 表单字段：
    - 招募标题（最多100字）
    - 项目名称
    - 项目图标（支持URL输入或本地上传）
    - 项目类型（竞赛/科研/创新创业）
    - 所需人数
    - 技能要求（多选标签）
    - 截止日期（日期选择器）
    - 项目描述（富文本）
    - 联系方式
  - 表单验证 + 提交按钮
  - 上传图标时图片预览

  7. RecruitDetail（招募详情）
  --------------------------------------------------
  - 返回按钮导航
  - 左侧主内容区：
    - 标题 + 状态标签 + 类型标签
    - 发布人信息、截止日期、发布时间、浏览次数
    - 所需技能标签
    - 人员招募进度条（已申请/所需）
    - 项目描述（Markdown渲染）
  - 右侧操作区：
    - "申请加入"按钮（非发布人可见）
    - 申请者列表
    - 发布人可操作：通过/拒绝申请、关闭招募

  8. TeamList（我的团队）
  --------------------------------------------------
  - 顶部：标题 + "创建团队"按钮
  - Tab切换：我创建的 / 我加入的
  - 团队卡片网格：
    - 团队头像
    - 团队名称 + 状态标签
    - 成员数、项目数、创建日期
    - 关联项目名称
  - 点击进入团队详情

  9. TeamDetail（团队详情）
  --------------------------------------------------
  - 返回导航
  - 团队信息卡片：头像、名称、状态、简介、成员数
  - 操作按钮：
    - 编辑团队信息（队长）
    - 解散/归档团队（队长）
    - 退出团队（非队长成员）
  - 成员列表网格（头像 + 姓名 + 角色标签 + 移除按钮）
  - 邀请成员功能
  - 关联项目列表
  - 团队动态/活动记录

  10. ProjectList（项目管理）
  --------------------------------------------------
  - 顶部：标题 + "创建项目"按钮
  - 骨架屏加载效果
  - 搜索 + 状态筛选
  - 项目卡片网格：
    - 项目头像、名称、状态标签
    - 所属团队
    - 任务进度条
    - 成员数、任务数
    - 创建日期、截止日期
  - 创建项目弹窗（表单：名称、团队选择、描述、截止日期）
  - 分页器

  11. ProjectDetail（项目详情）
  --------------------------------------------------
  - 返回导航
  - 项目头部卡片：头像、名称、状态、团队、创建时间、截止日期
  - 管理操作：关闭/重启项目（队长/管理员）
  - Tab切换：
    - 任务看板（按状态分组：待办/进行中/已完成）
    - 成员列表
    - 项目进度（ECharts甘特图）
    - 项目文件
  - 项目里程碑时间线
  - 项目描述

  12. TaskList（任务中心）
  --------------------------------------------------
  - 顶部：标题 + "新建任务"按钮
  - 视图切换：
    - 团队任务 / 我的任务 / 我管理的
  - 显示模式切换：
    - 看板视图（Kanban）：待办/进行中/已完成 三列拖拽
    - 列表视图：表格展示
  - 按项目分组开关
  - 任务卡片：标题、优先级标签、负责人头像、截止日期
  - 创建任务弹窗：
    - 选择项目、标题、描述、优先级
    - 指派成员（多人）
    - 截止日期
    - 里程碑关联
  - 任务状态流转（拖拽/点击改变状态）

  13. CompetitionList（竞赛中心）
  --------------------------------------------------
  - 标题横幅
  - 筛选条件：
    - 竞赛级别（国家级/省级/校级）
    - 类别（学科竞赛/创新创业/文体竞赛/其他）
    - 状态（报名中/进行中/已结束）
    - 关键词搜索
  - 竞赛卡片网格：
    - 竞赛名称、级别徽章
    - 主办方、报名时间范围
    - 状态标签
    - 收藏按钮
  - 分页器

  14. CompetitionDetail（竞赛详情）
  --------------------------------------------------
  - 返回导航
  - 竞赛头部：级别徽章、名称、状态标签、类别标签
  - 收藏/取消收藏按钮
  - 基本信息区：主办方、时间、官网链接
  - 竞赛介绍（富文本）
  - 参赛要求
  - 关联招募（该竞赛相关的招募项目列表）
  - 讨论评论区

  15. TeacherList（导师库）
  --------------------------------------------------
  - 标题区域
  - 筛选：按院系选择
  - 导师卡片网格：
    - 导师头像
    - 姓名、职称
    - 所属院系
    - 研究方向标签
    - 简介摘要
  - 邀请导师功能（从团队详情跳转时显示）
  - 分页器

  16. AchievementHall（成果展厅）
  --------------------------------------------------
  - Hero横幅：标题"荣耀殿堂"、成果总数/精选成果/总浏览量统计
  - 筛选Tab：全部/获奖证书/论文/专利/项目
  - 成果卡片网格：
    - 成果缩略图（证书/论文图片）
    - 成果标题
    - 成果类型标签
    - 获奖等级
    - 作者/团队成员
    - 发布时间
    - 浏览量、点赞数
  - 发布成果按钮
  - 分页器

  17. Profile（个人中心）
  --------------------------------------------------
  - 个人信息头部卡片：
    - 头像（支持点击上传更换）
    - 用户名、专业、年级、学号
    - 个人简介
  - Tab切换：
    - 基本资料编辑：手机号、姓名、专业、年级、简介
    - 技能标签管理（添加/删除）
    - 教育经历
    - 修改密码（旧密码 + 新密码 + 确认）
  - 保存按钮

  18. AiChat（AI助手）
  --------------------------------------------------
  - 左右分栏布局：
    - 左侧边栏：会话列表 + 新建对话 + 折叠/展开
      - 会话项：标题 + 消息数 + 删除按钮
    - 右侧聊天区：
      - 消息列表（用户/AI 对话气泡）
      - 流式输出（SSE实时显示AI回复）
      - Markdown渲染（marked + DOMPurify防XSS）
      - 输入框 + 发送按钮
      - 支持Enter发送
  - RAG知识库检索增强（基于项目和竞赛数据）
  - AI模型：DeepSeek（通过LangChain4j）
  - 欢迎引导界面
  - 自动滚动到底部

  19. AdminDashboard（管理后台）
  --------------------------------------------------
  - 仅管理员角色可访问（路由守卫拦截）
  - 数据概览统计面板：
    - 用户总数、团队总数、项目总数、招募总数
    - 今日新增/活跃用户
  - 用户管理Tab：
    - 用户列表表格（搜索、分页）
    - 编辑用户角色、封禁/解封
  - 招募管理Tab：
    - 招募列表表格
    - 审核/下架招募
  - 团队管理Tab
  - 项目管理Tab

  20. Layout（主布局组件）
  --------------------------------------------------
  - 左侧可折叠侧边栏：
    - Logo + 平台名称
    - 菜单项（带图标）：
      - 工作台 Dashboard
      - 招募广场 Recruit
      - 我的团队 Teams
      - 项目管理 Projects
      - 任务中心 Tasks
      - 竞赛中心 Competitions
      - 导师库 Teachers
      - 成果展厅 Achievements
      - AI助手 AiChat
      - 管理后台 Admin（仅管理员）
    - 当前路由高亮
  - 顶部栏：
    - 折叠按钮
    - 通知图标（未读数量徽章）
    - 用户下拉菜单：个人中心、退出登录
  - 右侧主内容区（router-view）
  ------------------------------------------------------------------

  四、API接口模块（16个模块）
  ------------------------------------------------------------------
  1.  user.ts         - 用户注册/登录/信息修改/头像上传
  2.  recruit.ts      - 招募CRUD/列表/申请/审核
  3.  team.ts         - 团队CRUD/成员管理/邀请
  4.  project.ts      - 项目CRUD/状态变更
  5.  task.ts         - 任务CRUD/指派/状态变更
  6.  competition.ts  - 竞赛列表/详情/收藏
  7.  teacher.ts      - 导师列表/邀请
  8.  achievement.ts  - 成果发布/列表/浏览
  9.  ai.ts           - AI聊天/SSE流式/会话管理
  10. dashboard.ts    - 工作台统计数据
  11. file.ts         - 文件上传/下载（签名URL）
  12. notification.ts - 通知/消息
  13. badge.ts        - 徽章系统
  14. certificate.ts  - 证书系统
  15. public.ts       - 公共接口
  16. request.ts      - Axios封装（拦截器/Token/错误处理）
  ------------------------------------------------------------------

  五、组件清单
  ------------------------------------------------------------------
  1. LoginDialog.vue       - 登录弹窗组件
  2. ThreeBackground.vue   - Three.js 3D背景动画组件
  ------------------------------------------------------------------

  六、路由守卫
  ------------------------------------------------------------------
  - beforeEach：未登录用户访问鉴权页面 → 重定向到首页
  - admin路由 meta.admin=true：非管理员 → 重定向到工作台
  - 动态页面标题设置（meta.title）
