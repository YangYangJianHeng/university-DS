# TabBar 图标说明

请将以下图标文件放置在此目录下：

| 文件名 | 用途 | 建议尺寸 |
|--------|------|----------|
| tab-home.png | 工作台(未选中) | 40x40 px |
| tab-home-active.png | 工作台(选中) | 40x40 px |
| tab-recruit.png | 招募(未选中) | 40x40 px |
| tab-recruit-active.png | 招募(选中) | 40x40 px |
| tab-team.png | 团队(未选中) | 40x40 px |
| tab-team-active.png | 团队(选中) | 40x40 px |
| tab-msg.png | 消息(未选中) | 40x40 px |
| tab-msg-active.png | 消息(选中) | 40x40 px |
| tab-mine.png | 我的(未选中) | 40x40 px |
| tab-mine-active.png | 我的(选中) | 40x40 px |

图标建议使用线性图标，未选中时颜色为 #909399，选中时颜色为 #667eea。

可以从 iconfont.cn 或 TDesign 图标库中获取。
