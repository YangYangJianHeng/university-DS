# PhysLab 实验业务域开发

## 域模型概览

```
Experiment (实验)
├── ResourcePackage (教学包：预习/视频/步骤)
├── SimulationSession (仿真会话)
│   ├── OperationLog (操作序列)
│   ├── DataPoint (采集点)
│   └── Replay (回放)
├── Report (报告)
│   ├── Template (分层模板)
│   └── Grade (批改/评分)
├── Assignment (发布任务)
└── Class (班级/学生组)
```

## 实验资源库

### 分层实验

| 层级 | 特点 |
|------|------|
| 高中 | 原理动画、填空/开放式报告、器材热点、语音讲解 |
| 大学 | 不确定度 A/B 类评定、原始记录规范、学术报告模板 |
| 自定义 | 教师积木拼装器材、多版本、校本审核上架 |

### 教学包组件

- 课前预习测验（客观题自动批改 + 错题解析）
- 操作引导视频、关键步骤语音提示
- 同一实验多版本（如不同摆长测 g）

### 智能推荐

依据历史成绩、薄弱知识点、进度推送实验；支持「每日一实验」任务。

## 数据采集与分析

### 记录方式

- 仪器「读取」自动填表；手动录入；语音标记（回放同步显示）。

### 图表与分析

- 折线/散点自动生成；线性、多项式、指数拟合。
- 异常点检测（黄点高亮 + 重测建议）。
- 误差：绝对/相对误差、误差棒；与标准值对比。
- 大学：A 类/B 类不确定度引导式表达。
- 对比：本人 / 理论 / 班级平均三曲线同屏。

### 导出

Excel/CSV 数据；图表 PNG；异步 MQ 处理大导出。

## 实验报告系统

### 模板分层

| 类型 | 适用 |
|------|------|
| 引导式填空 | 高中 |
| 学术规范 | 大学 |
| 教师自定义 | 校本 |

### 流程

1. 仿真结束 → 自动填充原理/步骤/数据/图表/结论
2. 学生富文本编辑 + LaTeX 公式
3. 提交前自检（数据点数、短路记录、异常点处理）
4. 教师批改：批注、评分细则、AI 预评语
5. 查重（文本 + 数据）；优秀报告可公开

## 教学管理

### 班级与发布

- 批量导入学生；创建班级。
- 实验发布：截止时间、评分权重。
- 差异化发布：不同组不同随机参数。
- 课堂同步：教师控制全体学生步骤。

### 进度与学情

- 完成状态、耗时、操作次数。
- 异常操作预警。
- 仪表板：知识点热力图、错误集中点、补弱建议。
- 成绩分布导出；家校周报（中学版）。

## 考核与防作弊

| 维度 | 机制 |
|------|------|
| 操作合规 | 接线顺序、短路、量程错误自动扣分 |
| 熟练度 | 操作序列分析、试错模式评估 |
| 数据真实 | 偏离度校验、伪造检测 |
| 动态难度 | 高分学生增加隐性故障/内阻干扰 |
| 限时随机 | 考核参数随机；功能禁用 |
| 生物特征 | 可选摄像头比对 + 键鼠行为（需授权） |

### 综合评分公式（可配置）

```
总分 = w1×数据误差分 + w2×操作规范分 + w3×报告完整度 + w4×熟练度
```

权重由教师在发布任务时设定。

## 社区与生态

- 教师分享自定义实验：评分、下载、版本控制。
- 学生讨论区；实验挑战赛排行榜。
- 创客空间：师生上传自创实验，审核后入库。
- 积分成就：器材皮肤、称号解锁。

## 典型业务流程：伏安特性曲线

参考 [开发文档.md](../../../开发文档.md) 第三节完整链路：

预习测验 → AI 引导搭建（安全顺序） → 连线纠错 → 采集与异常点提示 → 拟合对比 → 提交自检 → 教师回放批阅 + AI 评语。

实现时各步骤应对应明确的服务边界与状态机节点。

## 状态机：实验会话

```
CREATED → PREVIEW_DONE → IN_PROGRESS → DATA_COMPLETE → REPORT_DRAFT
    → SUBMITTED → GRADED
         ↘ ABANDONED / RESET
```

- `IN_PROGRESS`：仿真活跃，操作日志写入 MongoDB。
- `SUBMITTED`：触发查重与 AI 预批改异步任务。
- 考核模式额外记录 `violations[]` 供扣分。

## 开发检查清单

- [ ] 回放时间轴与评分扣分项关联
